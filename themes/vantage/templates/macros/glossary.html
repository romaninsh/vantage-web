{# ===== Glossary ===== Definitions live in `data/glossary.toml`, so a term reads the same on every page. #} {# A framework term with its definition on hover or keyboard focus, linking to its docs page when the glossary has one. `id` is the term's key in the glossary; `text` overrides the wording shown in the sentence, such as a plural; `code` sets the term as code, for file and key names. The output is used inside a sentence, so the whitespace control keeps it on one line: a newline around it would split the paragraph. The definition is inline markdown, so `backticks` mark identifiers; an entry's `example` shows as a code snippet under it.
