# Vantage 0.24

A path-shaped source can be browsed like a file manager. The new `finder` component puts a
breadcrumb and an expandable folder tree beside the selected folder's listing, with humanised byte
sizes and Finder-style timestamps. Expanding a folder opens just that path's data and collapsing it
closes it again, so a deep tree stays light.

## What's new

- Pointed at a live source, the listing moves on its own as files come and go.
- The selected path is published for the rest of the page to read.
